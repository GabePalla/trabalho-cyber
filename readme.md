1- Colocar o ip da tua máquina na const "IP" na linha 11.

2- Rodar os seguintes comandos.
  - python3 -m venv [o path onde o arquivo main.py está localizado]
  - source [o path aonde para a pasta /bin]/activate
  - pip3 install rsa
  - python3 main.py

3- Abrir dois terminais e escolher primeiro, em um dos terminais para ser host, e em outro para se conectar.

4- Enviar mensagens apertando enter.

1- Colocar o ip da tua máquina na const "IP" na linha 11.

2- Rodar os seguintes comandos.
  - python3 -m venv [o path onde o arquivo main.py está localizado]
  - source [o path da pasta bin (dentro dela)]/activate
  - pip3 install rsa

3- Abrir dois terminais e rodar o comando em ambos:
  - python3 main.py

4- Vai aparecer essa menssagem "Do you want to host (1) or to connect (2)?". Primeiro tu escolhe se tornar host em um dos terminais. Em seguida tu escolhe se conectar no outro terminal.

4- Enviar mensagens apertando enter.
